# 专业流程

复盘固定原著→划分来源单元→组织目标分集→比较删并拆增→准备目标候选→原著更新影响→局部返工。

原著和改编作品各自拥有正文与设定。插件在当前作品维护专业映射；外部目标仅是固定引用，Agent必须沿目标自己的management_ref核验并创建任务。不得把当前连接当成另一端已获权，不把改编例外写回原著。未知目标修订显示待核验。

- 原著部分未读，覆盖不能记为完整。
- 合并、拆分、省略、原创单元分别表达。
- 省略须无目标，新增须无来源，其他映射两端齐全。
- 来源更新仅标记影响，旧映射不漂移。
- 跨作品目标不扩大当前管理范围，单端读取不冒充双端成功。

旧来源与专业依据保持固定，更新以影响分析开始，不批量覆盖旧记录。

大工程写入和原键回读可传detail=summary，返回固定对象元数据及content_read；按固定修订export_project的8192字节JSON分块恢复完整工程。get_source按UTF-8偏移分块，complete只表示返回范围，不表示已理解全文。GUI可在受管桌面传输使用full；不能为机器入口切换all-tools或依赖窗口。
